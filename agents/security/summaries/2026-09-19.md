## Critical Finding: protobufjs RCE (57 Days Unpatched)

### The Problem

A **CRITICAL remote code execution vulnerability** exists in `protobufjs@7.5.4`, a transitive dependency used by Docker API client (`dockerode`). An attacker who can control protobuf messages sent to the Docker gRPC interface could execute arbitrary code.

### Timeline

- **2026-08-23:** Vulnerability discovered in security audit
- **2026-08-31:** Still unpatched (network issues prevented verification)
- **2026-09-08:** Still unpatched (confirmed version 7.5.4)
- **2026-09-14:** Still unpatched (no dependency changes)
- **2026-09-19:** **STILL UNPATCHED** (confirmed version 7.5.4) - **57 DAYS**

### Impact

- **Exploitability:** Moderate (requires attacker-controlled protobuf messages reaching Docker API)
- **Severity:** CRITICAL (arbitrary code execution)
- **Affected Packages:** `packages/chat`, `packages/core`
- **Dependency Path:** `dockerode → @grpc/grpc-js → @grpc/proto-loader → protobufjs@7.5.4`

### Required Fix

```bash
pnpm update protobufjs @grpc/proto-loader @grpc/grpc-js dockerode
# Expected result: protobufjs@7.5.5 or higher
```

**Status:** Unpatched for **57 days** - IMMEDIATE action required.
