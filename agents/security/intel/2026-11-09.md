### Critical Vulnerability Details

**1. protobufjs 7.5.4 - CVE-2026-41242 (GHSA-xq3m-2v4x-88gg)**
- **CVSS Score:** 9.8 (Critical)
- **Type:** CWE-94 - Arbitrary code execution via crafted JSON descriptor
- **Attack Vector:** Network, Low complexity, No privileges required
- **Affected Versions:** protobufjs >= 7.0.0 < 7.5.5
- **Fixed Version:** protobufjs >= 7.5.5
- **Dependency Path:** Multiple paths via dockerode dependency:
  ```
  @herdctl/core > dockerode@4.0.9 > protobufjs@7.5.4
  @herdctl/core > dockerode@4.0.9 > @grpc/grpc-js > @grpc/proto-loader > protobufjs@7.5.4
  ```
- **Preconditions for Exploit:**
  1. Application must allow attacker to control protobuf definition or JSON descriptor
  2. Application must load that definition through protobufjs reflection APIs
  3. Affected generated-code path must be reached
- **herdctl Impact Assessment:** LOW
  - herdctl does not load protobuf definitions from untrusted sources
  - dockerode uses protobufjs for gRPC communication with Docker daemon
  - Docker daemon is a trusted component (localhost socket)
  - No user-controlled protobuf schemas in herdctl's usage
- **Remediation Status:** MONITORING
  - Waiting for dockerode upstream to update protobufjs dependency
  - Not blocking - exploitability in herdctl context is minimal
  - Will update when new dockerode version available
