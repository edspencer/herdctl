### Critical Security-Relevant Commits

#### 1. **MCP HTTP Bridge Authentication** (CRITICAL FIX)
**Commit:** bf4995a50f3dd9d84ba9bb2987d39bd39194597e  
**PR:** #467  
**Date:** 2026-09-27  
**Impact:** Fixes Finding #054 (related to #012)

**What Changed:**
- Added bearer token authentication to MCP HTTP bridge
- Bridge now generates random 256-bit token per instance
- Rejects requests without `Authorization: Bearer <token>` (401)
- Token comparison uses constant-time algorithm (timing attack protection)
- Binds 127.0.0.1 by default (localhost only)
- Container runtime uses 0.0.0.0 with token auth (necessary for Docker)
- MCP config written to owner-only temp file (0600 permissions)
- Tokens passed via headers, not argv (prevents process table exposure)

**Security Analysis:**
- ✅ **Excellent fix** - addresses unauthenticated network service
- ✅ Proper cryptographic token generation (256-bit random)
- ✅ Constant-time comparison prevents timing attacks
- ✅ Localhost binding by default reduces attack surface
- ✅ File permissions protect tokens at rest (0600)
- ✅ Comprehensive test coverage (243 new test lines in cli-runtime.test.ts)

**Files Modified:**
- `packages/core/src/runner/runtime/mcp-http-bridge.ts` (+75 lines)
