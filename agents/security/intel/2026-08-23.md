#### 6. ⚠️ CLI Session Adoption (9a0d037, 2026-08-01)

**Impact:** NEW FEATURE - STRONG CONTROLS

**Changes:**
- `adoptSession()`, `adoptSessionsFrom()`, `unadoptSession()` APIs
- Adoption records at `.herdctl/adopted-sessions/<session-id>.yaml`
- Never-clobber guarantees: COPYFILE_EXCL for copy, hard link for move
- Dry-run mode writes nothing (not even cache files)
- TOCTOU-safe: Hard link then unlink source (rejects occupied destination)
- Exports `CLAUDE_CONFIG_DIR` env var to control session location

**Security Controls (10 layers):**
1. Never-clobber guarantee (syscall-level COPYFILE_EXCL, EEXIST rejection)
2. Path validation (session IDs are UUIDs from SDK)
3. Atomic operations (hard link + unlink, not rename which silently clobbers)
4. Dry-run isolation (`persistSidechainCache: false`)
5. TOCTOU protection (single `link()` + `unlink()` - no stat() pre-check window)
6. Cleanup on failure (removes orphan copy)
7. CLAUDE_CONFIG_DIR injection (never sets `process.env`, only per-query/per-spawn)
8. Symlink attack blocked (hard link rejects if destination exists, even as dangling symlink)

**Question Q6 Status:** ✅ **ANSWERED**
- Session IDs are UUIDs from SDK (safe from path traversal)

**Assessment:** Excellent defense-in-depth. All TOCTOU and race conditions addressed.

#### 7. ⚠️ Inline Agent Images (28d4d74, 2026-07-21)

**Impact:** NEW ATTACK SURFACE - COMPREHENSIVE CONTROLS

**Changes:**
- New file serving endpoint: `GET /files/:agentName/*`
- Image preservation in tool results and assistant messages
- `extractImageBlocks()`, `normalizeImageBlock()`, `imageToDataUrl()` helpers

**Security Controls (10 layers):**
1. **Structural validation:** `isStructurallySafe()` rejects absolute paths and `..` segments
2. **Agent name validation:** Uses existing `AGENT_NAME_PATTERN` enforcement
3. **Realpath resolution:** Both working directory and target resolved via `realpath()` (defeats symlinks)
4. **Containment check:** `relative()` verifies resolved path stays within working directory
5. **TOCTOU protection:** Opens file **once** with `open(realPath, "r")`, then `fstat()` and `createReadStream()` from same fd
6. **File type validation:** Rejects directories and non-regular files
7. **CSP headers:** `Content-Security-Policy: default-src 'none'; sandbox` (prevents script execution)
8. **MIME control:** `X-Content-Type-Options: nosniff` (prevents MIME sniffing attacks)
9. **Error handling:** 403 for traversal, 404 for missing, 500 for unexpected
10. **Type guard:** Uses `isAgentNotFoundError()` instead of string matching

**Attack Scenarios Tested:**
- ✅ Path traversal with `..` segments: Blocked
- ✅ Symlink escape: Blocked by realpath
- ✅ TOCTOU symlink swap: Blocked by single file descriptor
- ✅ XSS via malicious SVG: Blocked by CSP sandbox
- ✅ MIME sniffing: Blocked by `X-Content-Type-Options: nosniff`

**Code Review Highlight:**
```typescript
// BEFORE CodeRabbit review: TOCTOU window
const stats = await stat(resolved);
return reply.send(createReadStream(resolved)); // Path could change here!

// AFTER fix: TOCTOU-safe
const handle = await open(realPath, "r");
const stats = await handle.stat();
return reply.send(handle.createReadStream()); // Same fd, immutable
```

**Finding #012 Relationship:**
- Same authentication gap (localhost-only design)
- Assumes localhost trust boundary

**Recommendations:**
- 🟡 Consider: Add rate limiting (defense against enumeration)
- 🟡 Consider: Add request logging for security monitoring
