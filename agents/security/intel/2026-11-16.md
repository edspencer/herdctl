### Test Improvements (Commit 848fcb0)

**Purpose:** De-flake scheduler timing tests and real-Docker container tests

**Changes:**
1. **docker-security.test.ts:** Increased timeout from 5s to 30s for "Container Configuration" suite
   - Prevents timeouts on cold/busy CI runners when shelling out to `docker create` / `inspect` / `rm`
   - No security impact - test-only change

2. **scheduler.test.ts:** Replaced fixed `wait(n)` with polling `waitUntil()` helper
   - Prevents race conditions on loaded CI runners
   - Waits exactly as long as needed instead of guessing runner speed
   - Uses `performance.now()` (not `Date.now()`) to avoid interaction with frozen time in tests
   - No security impact - test-only change

**Security Assessment:** These changes improve test reliability without affecting production code or security controls.
